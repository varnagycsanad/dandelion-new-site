# DWA Lenovo specialist instructions

## RUNTIME ROLE - current architecture v1

This is the Lenovo-side website specialist repository. Website development, builds, SEO, UX, and site-side tracking work run on Lenovo. The normal manual workflow does not use the ASUS bridge, queue, or worker. ASUS is not a general web-development machine. Deployment requires a separately approved release/deploy process. Repo-local build and deploy safety rules remain mandatory.
