## Kovetkezo implementacios csomag elofeltetelei

Gyors dontesi blokk csak akkor indulhat, ha:
- [ ] kisallat, wifi, parkolas, legkondi, medence statuszok tisztazva
- [ ] furdok szama es agyelrendezes tisztazva
- [ ] kinek ajanlott / kinek nem ajanlott mezok megvannak

CTA linkesites csak akkor indulhat, ha:
- [ ] minden HU booking link jovahagyva
- [ ] minden EN booking link jovahagyva

- [ ] a fenti adatok lathato oldaltartalomba is bekerulnek
- [ ] nincs bizonytalan adat, amit schema-ba kellene irni
- [ ] VacationRental / Google booking irany tisztazva

- [ ] kepenkenti vizualis ellenorzes megtortent
